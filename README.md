# PhotoEdit Lite

PhotoEdit Lite is a lightweight browser-based image editing application developed as the demonstration software for the BlockVerify MSc project.

## Features

- Image upload
- Brightness adjustment
- Contrast adjustment
- Grayscale
- Blur
- Image rotation
- Horizontal flip
- Vertical flip
- Zoom
- Image reset
- PNG download

## Technology

- HTML5
- CSS3
- JavaScript
- Canvas API

## Version

v1.0.0

## Purpose

PhotoEdit Lite is used as a controlled software artifact for testing the BlockVerify blockchain-based software integrity and provenance verification system.
